## 踩过的两个真 bug（重要）

1. `writeBatch` 里 `await get()` 之后再 `put()` —— IndexedDB 事务在事件回调返回后失活，写入静默丢失。修法：`put` 必须放在 `get` 的 `onsuccess` 回调内部同步发起，事务完成监听也要同步注册。
2. Pinia 响应式 Proxy 对象直接 `os.put()` 会触发 DataCloneError。修法：写入前 `structuredClone(toRaw(...))` 脱代理。

## 自测与修复（第二轮）

用 headless Chrome CDP 复现 + 修复三处问题，修复后 smoke 20/20 全过、build 通过：

1. **【Bug·高】deleteGoal 连任务删除时未收尾开放行动**（`src/stores/app.ts`）：删除带进行中任务的目标后 `openActionId` 悬空，之后开始任何任务都弹「还有一件事没收尾」冲突弹窗指向已删的幽灵任务。修法：`mode='delete'` 时把 open action 一并收尾（abandoned/valid=false）并清 `openActionId`/`timerEndsAt`，合入同一次事务。
2. **【UX·高】Sheet 弹窗**（`src/components/Sheet.vue`）：补 Esc 关闭 + 打开时 `documentElement.overflow=hidden` 锁背景滚动，多 Sheet 叠加用 `dataset.sheetCount` 引用计数，最后一个关闭才解锁。
3. **【性能·中】ActionView 计时器**（`src/views/ActionView.vue`）：原来无条件每秒 setInterval；改为 watch `remaining`，倒计时进行中才启停 ticker，归零即挂起。

复现脚本要点（临时已删）：CDP 驱动 Chrome，注意 waitText 超时要 throw 否则流程静默漂移；records 页 tab 与 QuickAdd 内 chip 都含「待办」字样，选择器必须限定 `.sheet .chip`；`location.hash` 直接跳转比模拟点击 GoalCard 稳。

## 开发环境端口改为 6173

`vite.config.ts` 的 `server.port` 由 5173 改为 6173，并加 `strictPort: true`——Vite 默认端口被占用会静默顺延到下一个端口，导致「以为改了其实没生效」。全项目仅此一处定义 dev 端口：`scripts/smoke-test.mjs` 里的 4173 是 `vite preview` 默认端口、9333 是 Chrome 远程调试端口，均不涉及开发环境，未改动。验证：已在运行的 vite 进程（PID 10700）随配置热更新自动重启至 6173，`curl http://127.0.0.1:6173/` 返回 200 且为带 `/@vite/client` 的 dev 首页，5173 已无监听。
